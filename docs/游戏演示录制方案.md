# Word Quest 游戏演示视频 — 演示脚本 & 录制方案

## 一、录制软件推荐

### 方案A：OBS Studio（推荐）
- **优点**：完全免费、开源、无水印、不限时长、支持1080P/4K、可自定义录制区域
- **设置要点**：
  - 输出模式选"简单"，录像路径设桌面
  - 输出分辨率 1920×1080，帧率 30fps 即可
  - 音频：勾选"录制桌面音频"（关闭麦克风，不要录入解说声）
  - 编码器选 x264，码率 2500-4000 Kbps
- **下载**：https://obsproject.com

### 方案B：Windows 自带录屏（Win+G）
- **优点**：零安装、快捷键 Win+Alt+R 开始/停止
- **缺点**：只能录制全屏应用窗口，无法自定义区域，格式为 mp4

### 方案C：数据蛙录屏软件
- **优点**：免费无水印、不限时长、界面简单、支持区域录制
- **下载**：搜索引擎搜"数据蛙录屏"

### 录制通用建议
- 分辨率 1920×1080，浏览器全屏（F11）
- 提前关闭无关程序，关闭系统通知
- 游戏音量适当，不要太大也不要静音
- 每段独立录制一个文件，后期拼接比一镜到底更灵活
- 建议总时长控制在 **3-5分钟**（答辩演示不要太长）

## 二、演示脚本（总时长约3-4分钟）

### 准备工作（录制前）
1. 确保服务器和前端都已启动并正常运行
2. 准备一个测试账号（或用注册功能现场演示登录）
3. 确保数据库中有足够的学习数据（仪表盘页面需要）
4. 清理浏览器缓存，确保从登录页开始
5. **关键准备**：确保第1关、第2关、第3关分别出现不同题型（选择题→拼写题→中译英），如果自适应难度未触发，需要手动调低/调高难度或用多个账号制造答题数据
6. 提前准备一个有答题记录的账号，确保仪表盘和错词本有数据可展示

---

### 第1段：关卡选择 → 第1关选择题（约40秒）

**操作流程**：
1. 从主菜单进入关卡选择界面 → 展示6章×5关、星级、解锁机制
2. 选择第1关，难度"普通" → 进入游戏地图
3. 用方向键移动角色，展示地图布局
4. 走向怪物 → 触发**英译中选择题**
5. 选择正确答案 → 怪物消灭动画 + 连击提示
6. 继续答2-3道选择题 → 展示连击数

**展示要点**：
- 关卡选择界面和星级系统
- 像素风游戏地图
- **第1关题型：选择题**（最低难度）
- 连击机制

---

### 第2段：第1关结算 → 第2关拼写题（约40秒）⚠️ AI核心

**操作流程**：
1. 清完第1关怪物 → 进入关卡结算界面（展示星级、得分、正确率）
2. 自动进入第2关（或手动选择）
3. 走向怪物 → 弹出**提示拼写题**（注意：题目类型已从选择题升级为拼写题）
4. **故意拼错一个字母**（如 abandon → abanden）→ 展示**模糊评分**提示（"接近正确"+ 部分得分）
5. 再答对一道拼写题 → 连击继续

**展示要点**：
- ⭐ **题型动态升级**：选择题 → 拼写题（自适应难度算法生效）
- ⭐ **模糊评分**：拼写接近时给"接近正确"提示而非直接判错
- 关卡结算界面

---

### 第3段：第2关结算 → 第3关中译英（约40秒）

**操作流程**：
1. 第2关结算 → 进入第3关
2. 走向怪物 → 弹出**中译英题目**（题型再次升级）
3. 输入英文单词 → 答对/答错的反馈
4. 继续答题至第3关完成
5. 第3关结算

**展示要点**：
- ⭐ **题型三连升级**：选择题 → 拼写题 → 中译英（完整展示动态难度调整过程）
- 答题反馈动画

---

### 第4段：AI学伴"小智"对话（约50秒）⚠️ AI核心

**操作流程**：
1. 在游戏中走向NPC"小智"（奶牛精灵）→ 触发AI对话面板
2. 点击**"记忆技巧"**快捷按钮 → 展示AI流式输出记忆方法
3. 点击**"词根分析"**快捷按钮 → 展示AI返回词根词缀拆解
4. 在聊天框手动输入一个问题，如"abandon这个词怎么记？" → 展示AI流式回复
5. 关闭对话面板

**展示要点**：
- ⭐ AI对话的**SSE流式输出**效果（逐字出现）
- 上下文感知：AI知道当前学习的单词和玩家状态
- 6种场景化Prompt（记忆技巧、词根分析、例句、近义词）

---

### 第5段：学习仪表盘（约40秒）

**操作流程**：
1. 返回主菜单 → 退出到浏览器导航栏
2. 输入 `/dashboard` 进入学习仪表盘
3. 展示**掌握率饼图**（停留3秒）
4. 展示**每日学习趋势折线图**（停留3秒）
5. 展示**章节正确率雷达图**（停留3秒）
6. 滚动展示**易错词Top 10**
7. 点击排行榜 → 展示排行榜界面

**展示要点**：
- ECharts三种图表（饼图、折线图、雷达图）
- 学习数据分析的全面性
- 排行榜的社交激励机制

---

### 第6段：错词复习（约30秒）

**操作流程**：
1. 返回游戏主菜单 → 选择"错词复习"
2. 展示错词复习界面（列出之前答错的词汇）
3. 答对几道复习题 → 展示正确率提升
4. 返回主菜单

**展示要点**：
- ⭐ **学习闭环**：答错的词自动进入错词本 → 复习巩固 → 移出错词本
- 完整的"学习→检测→诊断→复习→巩固"闭环

## 三、演示路线总结


## 五、录制注意事项

1. **提前彩排至少2遍**：熟悉操作流程，确保三关题型确实按顺序升级（选择题→拼写题→中译英）
2. **操作要慢**：每一步停留2-3秒让评委看清，不要太快划过
3. **重点功能多停留**：模糊评分拼写、AI对话流式输出、仪表盘图表这些亮点多展示几秒
4. **录制时不要解说**：录制纯游戏画面，答辩时播放视频同步口头解说
5. **准备B计划**：如果某个功能出bug，准备跳过或切换到备用演示内容
6. **分文件录制**：每段录一个文件，命名如 `01_第1关选择题.mp4`、`02_第2关拼写.mp4`… 方便后期拼接
7. **拼接工具**：用剪映（免费）拼接即可
8. **题型升级验证**：录制前先测试一遍，确认第1关出选择题、第2关出拼写题、第3关出中译英。如果未触发升级，可通过多次答对或调整难度设置来触发
9. **模糊评分效果**：第2关拼写题一定要故意拼错一个字母，这是展示模糊评分算法的关键镜头
10. **AI对话前提**：确保llm-service已启动且千问API可用，否则小智无法回复
