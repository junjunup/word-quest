# 5.3 算法验证与评估结果

上一章设计了干扰项生成、拼写模糊评分和自适应难度调节三个算法，这一节对它们做定量评估，验证实际效果。评估分为两部分：先说明用了哪些评价指标，再给出评估结果。

## 5.3.1 评价指标

对三个算法分别定义了评价指标。

干扰项生成算法方面，用了三个指标：语义相关性（SR），衡量干扰项和正确答案之间有没有关联，由人工按1-3分打分，1分是毫无关系、3分是有关联但不算同义词；区分有效性（DV），衡量干扰项能不能把"会"和"不会"的学生区分开，核心要求是干扰项不能是正确答案的同义词，且中文释义的Jaccard系数不能超过0.9，满足条件的干扰项占比即为DV值；选项多样性（OD），看4个选项在词性和语义类别上的覆盖广度，满分8分。

拼写模糊评分算法方面，核心指标是判定一致性（CON），即算法把答案分为exact/near/wrong三档后，跟人工标注的吻合比例。此外关注两个错误率：近误判率（NFPR），指把本该判"错"的答案误放成了"接近正确"；远漏判率（FFNR），指把本该算"接近正确"的误判为"完全错误"。其中NFPR最关键，因为这意味着学生白拿分。

自适应难度算法方面，主要看难度匹配度（DM），即系统推荐的难度下学生正确率是否处于60%-80%的理想区间。另外统计了保护机制的触发情况，验证连错降级和冷启动保护是否正常运作。

## 5.3.2 评估结果与分析

干扰项生成方面，从系统6章30关中随机抽取100道选择题做对照实验，实验组用语义特征融合算法选干扰项，对照组纯随机抽取，由两名英语专业研究生独立打分。结果如表5.5所示。

表5.5 干扰项生成算法对照评估结果

| 评估指标 | 实验组（语义融合算法） | 对照组（随机抽取） | 提升幅度 |
|---------|---------------------|-----------------|---------|
| 语义相关性SR（均值） | 2.71 | 1.35 | +100.7% |
| 区分有效性DV | 96.3% | 63.7% | +51.2% |
| 选项多样性OD（均值） | 6.2 | 4.1 | +51.2% |
| 同义干扰项误判率 | 1.2% | 18.5% | -93.5% |

实验组在三项指标上都明显优于对照组。语义相关性从1.35提高到2.71，随机抽出来的干扰项很多跟正确答案没关系，学生一眼就能排除。区分有效性方面对照组将近五分之一（18.5%）的干扰项是同义词，比如正确答案是"achieve"却出现了"accomplish"，而实验组控制在1.2%。多样性6.2分（满分8）说明算法对词性和语义类别的覆盖约束起了作用。

拼写模糊评分方面，手动构造了200组拼写测试样本，覆盖词长3-14字母、编辑距离0-5、以及漏字母、多字母、替换、颠倒等多种错误类型，由两名英语教师独立标注。结果如表5.6所示。

表5.6 模糊评分算法一致性评估结果

| 指标 | 数值 |
|------|------|
| 总体一致性CON | 93.5% |
| exact判定一致率 | 100.0% |
| near判定一致率 | 88.3% |
| wrong判定一致率 | 94.0% |
| 近误判率NFPR | 3.2% |
| 远漏判率FFNR | 6.7% |

总体一致性93.5%，exact档100%不存在争议，near档88.3%略低主要是因为部分边界case标注者之间也有分歧。近误判率只有3.2%，说明按词长分档的阈值保护机制有效，短词（1-4字母）误判率为0%，长词额外加的相似度门槛（≥0.78）也过滤掉了词形相近但含义不同的干扰。另外用10个测试用户做了对照实验，模糊评分组的任务完成率（93.3% vs 80.0%）和继续意愿（90% vs 60%）都明显高于精确匹配组，挫败感自评从3.4降到2.1，说明near这个中间态确实有助于学生保持学习动力。

自适应难度方面，模拟了优秀型、良好型、波动型、困难型和渐进型五种学生行为模式，每种模拟100次连续答题。结果如表5.7所示。

表5.7 各学生行为模式下的难度匹配度

| 学生类型 | 模拟答题数 | 最终稳定难度 | 稳定后平均正确率 | 难度匹配度DM |
|---------|----------|----------|-------------|-----------|
| 优秀型 | 100 | 4-5级 | 72.3% | 0.89 |
| 良好型 | 100 | 3级 | 68.7% | 0.94 |
| 波动型 | 100 | 2-3级 | 65.1% | 0.86 |
| 困难型 | 100 | 1-2级 | 71.5% | 0.91 |
| 渐进型 | 100 | 1→3级 | 70.8% | 0.92 |

五种模式稳定后正确率都在65%-75%之间，接近理想值70%。困难型学生在降级保护下正确率回到71.5%，没有陷入越做越难的恶性循环。渐进型用户在前30题中难度从1级平稳上升到3级，之后稳定在3级正确率71%左右，轨迹很平滑，说明算法能跟随学生能力变化及时调整。

三项保护机制中，单次升降限制（最多±1级）在100题中触发了23次，完全杜绝了难度跳变；连错降级保护触发了15次，平均连错2.3次后完成降级；冷启动时前10题通过置信度折减将能力值权重从45%线性拉到100%，避免初期波动。

最后测了一下系统性能，三个自研算法的总计算开销不超过60ms（干扰项45ms+评分不到1ms+自适应12ms），远低于AI学伴对话的1.2秒，不会对用户体验造成影响。
